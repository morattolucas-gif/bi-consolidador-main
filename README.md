# B.I. Consolidador — Propósito Capital

Painel de posições e alocações da carteira, em um único arquivo (`index.html`) que roda no navegador.

Site: https://proposito-capital.github.io/bi-consolidador/

**Este repositório contém só o código.** Os extratos, o cadastro de clientes e o histórico de cada pessoa ficam no computador e no navegador dela: nada disso é enviado para o site ou para este repositório.
